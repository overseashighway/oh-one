# OH ONE

Overseas Highway's internal CRM and business operating system.

## Technology direction
- PHP / Laravel modular monolith
- MySQL database, administered using phpMyAdmin
- GitHub for version control
- cPanel deployment after environment checks

## First milestone
1. Verify hosting PHP, Composer, database and document storage support.
2. Scaffold Laravel in a development environment.
3. Implement authentication and office-scoped authorization.
4. Build Leads → Students → Applications workflow.
5. Add tasks, partners, finance, audit logs and reporting in stages.

**Status:** Planning and repository bootstrap only. Application is not yet installed or deployed.
